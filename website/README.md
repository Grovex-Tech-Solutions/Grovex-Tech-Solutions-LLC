# GroveX private notice

The public site is intentionally a minimal, dependency-free notice. GroveX is a private systems operation and does not accept clients, users, investors, or access requests.

## Commands

- `npm test` validates the notice, crawler policy, and legacy-route fallback.
- `npm run lint` syntax-checks the test.
- `npm run build` copies `public/` to the Cloudflare Pages artifact at `out/`.
