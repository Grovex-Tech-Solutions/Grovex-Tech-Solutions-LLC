# GroveX pixel art assets

Crisp SVG visual assets for GroveX cards, hero panels, and proof surfaces.

Design rules:
- serious teal/blue systems palette
- no emoji-based UI
- accessible alt text at use sites
- SVG shape-rendering uses crispEdges for pixel-art feel
- static-hosting safe under /pixel_art/*

Assets generated by scripts/generate-pixel-art.mjs.
